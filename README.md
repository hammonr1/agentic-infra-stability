# agentic-infra-stability
Stability analysis of city infrastructure run by coupled AI agents. Models physical and agent-layer deficits as a positive system d_{t+1} ⪯ K(y) d_t and asks how much authority, communication, and mitigation keep ρ(K) &lt; 1.
